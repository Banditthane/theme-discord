# Record Decision

Use `.cawf/templates/decision.md`. Record context, recommendation, alternatives, benefits, trade-offs, risks, criteria, status, affected modules/contracts, consequences, validation/fitness checks and supersession links. Do not create ADRs for trivial details. Obtain approval before accepting high-impact decisions.

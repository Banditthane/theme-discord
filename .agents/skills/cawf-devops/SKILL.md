# DevOps / Delivery

Separate build/test configuration from deployment mutation. Verify reproducibility, least privilege, secret handling, artifact/version integrity, rollback path, and environment differences. Deployment, publish, infrastructure apply, destructive, and external writes require explicit approval; dry-run/plan/read-only evidence is preferred first.

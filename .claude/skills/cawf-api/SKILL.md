# API Contract

Treat externally consumed shapes and semantics as versioned contracts. Define identifiers, required/optional/null behavior, validation, errors, pagination/filtering when relevant, idempotency/deduplication for retryable writes, authentication/authorization, and backward compatibility. Verify both producer and known consumers before acceptance.

# Frontend

Start from user flow and existing component/design conventions. Keep presentation, client state, server state, and API contracts distinct. Verify responsive behavior, keyboard/focus/accessibility, loading/error/empty states, hydration/render risks when applicable, bundle/runtime regressions, and targeted browser evidence only when useful.

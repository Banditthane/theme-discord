# Focused Inspection

1. State one question, supplied paths/symbols and budget.
2. Use `explorer`; search outward only when evidence requires it.
3. Stop when enough evidence answers the question or budget is reached.
4. Save compressed evidence in run-local `evidence/`; no raw logs by default.
5. Include exact paths/symbols, facts vs inference, risks and unknowns.
6. Never treat this as permission for a full scan.

# CAWF Generic Security Review

Review only the affected attack surface. Prioritize identity/authentication, authorization, input validation, ownership, secrets, unsafe deserialization/command execution, network boundaries, persistence/transactionality, replay/rate abuse, and dependency risk when relevant.

Do not claim a complete security audit from heuristics alone. Security/permission changes require the configured approval gate. Return file/line evidence, severity, exploit preconditions, proposed mitigation, and verification steps.
